# Agentic Chatbot for SafeX Solution

An intelligent, multi-agent AI assistant designed for **SafeX Solutions**. 
Equipped with autonomous reasoning, tool execution, safety compliance checks, customer support, and system monitoring.

## 🚀 Key Features
- **Agentic Decision Making**: Goal-oriented agent with memory, planning, and tool use.
- **Safety & Compliance Protocols**: Instant verification against safety regulations, incident reporting, and hazard analysis.
- **Interactive Knowledge Base**: Dynamic retrieval for SafeX services, documentation, and technical support.
- **Modern Responsive Web UI**: Real-time streaming conversation, visual status cards, and interactive action triggers.

## 🛠️ Tech Stack
- **Backend**: Python (FastAPI / Agent Architecture)
- **Frontend**: Modern Responsive Web Interface (HTML5, Vanilla CSS, JavaScript)
- **Agent Framework**: Multi-tool agentic loop with custom tools & knowledge retrieval
