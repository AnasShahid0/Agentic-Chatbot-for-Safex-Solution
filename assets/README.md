# Project Assets & Screenshots

This directory stores visual assets, architecture diagrams, and application screenshots for the **SafeX Solutions Agentic Chatbot & Incident Management Platform**.

## Screenshot Guidelines for Documentation:
When testing or running the platform (`http://127.0.0.1:8000`), capture and store screenshots here with the following recommended filenames:

1. `dashboard-overview.png`: Main chatbot UI with glassmorphism header, status indicator, and prompt suggestion pills.
2. `agentic-tool-execution.png`: Chain-of-thought drawer showing the agent selecting tools (`check_system_health`, `safety_compliance_audit`, `dispatch_emergency_team`).
3. `incident-management.png`: Incident log panel showing tracked active events, severity badges, and auto-generated ticket IDs.
4. `mobile-responsive-view.png`: Mobile / compact viewport testing.

All screenshots placed in this folder will be rendered directly in the root [README.md](../README.md).
